## Scientific / presentation accuracy

- DORA = Discover → Offer → Request → Acknowledge.
- ARP resolves a local IPv4 neighbor's MAC, not the remote site's MAC.
- DNS to an external resolver may traverse the Internet; it is **not** a forwarding hop on every webpage flow.
- Home NAT/PAT is an address/port translation mechanism, not a mandatory transport protocol.
- The browser–observer–server depiction is a conceptual on-path visibility demo, not a literal three-node Internet route.
- HTTP traffic content is readable to an on-path observer if unencrypted; HTTPS application content is protected by properly authenticated TLS. IP/port/timing metadata may remain visible.
